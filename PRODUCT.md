# World Wide Maze

World Wide Maze turns website layouts into a marble maze, using a browser renderer and deterministic Rapier physics. Existing practice, phone-control, replay and educational workflows remain the product baseline.

The local Jev spectator experiment lets the developer watch a typed AI selector explore curated mazes. Website score runs use the existing website maze library, including page sections, and show live gem points, remaining time and the best completed local Jev score for the same stage. Jev chooses gem targets or the goal from the visible board; the local physics controller executes each route. A run uses one ball, with the simulation clock paused during decisions. Legacy authored runs retain their adjacent-connection exploration mode. Success means seeing a real run, understanding each observed decision, and revisiting the complete saved evidence and replay. Baseline and scripted policies are explicitly labeled.

The approved spectator surface is a large maze viewer with an adjacent decision notebook, persistent controls, history, and mobile notebook collapse. Extend the incumbent Figtree/Unbounded, ink/teal, cut-corner game identity. No public deployment or product-wide redesign is included.
