# WWM Learning

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Parents selecting and personalizing a default learning path; children ages 4–6 playing alongside a grown-up. Age is a suggested audience, not an assessment or a restriction.

## Product Purpose

Publish useful, child-friendly education pages with explicit learning intent that compatible games can read. Keep education, game mechanics, and learner history separate.

## Operating Context

The parent starts with baseline material, uses AI to propose a personal spin, reviews it, and accepts a family fork. This workflow and the initial age range were confirmed in the September 26 conversation. WWM is the first intended game consumer.

## Capabilities and Constraints

This first implementation is a local, static-site pilot: six early-math activities, transparent parent notes, versioned HTML data, local customization, and a bring-your-own-AI prompt/import workflow. This is a bounded implementation choice, not a claim that math covers the whole age band. No accounts, provider integration, cloud learner record, educational certification, or in-maze lesson triggers are included yet.

## Product Principles

- A parent can see the same educational intent a game reads.
- Begin with useful default material; personalization is optional.
- Preserve the baseline and make proposed changes reviewable and reversible.
- Activity participation is not evidence of mastery.
- Wrong answers invite help and another attempt; activities remain freely selectable.

## Evidence on Hand

The existing game lives in apps/web. Its Figtree/Unbounded typography and bright geometric color roles provide the incumbent visual system. The starter activities are original pilot content requiring educator and family review, informed by sources recorded in docs/education/content-notes.md.

## Open Decisions

Product name beyond the working label WWM Learning; account ownership; AI provider; published forks; curriculum review; broader age groups and commercial model.
