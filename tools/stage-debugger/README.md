# @wwm/stage-debugger

Visual debugger that renders each stage-builder step as a toggleable layer over the screenshot.

**Status:** scaffold (Phase 02). Owned and implemented by **Phase 03** — see `plans/phase-03-*.md`.

- Contract types come from `@wwm/schema` (never redeclare them).
- Tests: `pnpm vitest run --project @wwm/stage-debugger` (or `pnpm test` at the root).
- Typecheck: `pnpm --filter @wwm/stage-debugger typecheck`.
