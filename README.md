# World Wide Maze revival research

Research date: September 24, 2026 (America/Los_Angeles).

World Wide Maze offers a useful starting point for a playable tribute to inventive web development and an honest demonstration of present-day AI-assisted engineering.

- [Historical research and reading guide](research/world-wide-maze.md)
- [Proposed recreation and AI showcase](research/recreation-plan.md)
- [Machine-readable recovery evidence](research/recovery-evidence.json)

Status: research and proposed scope. No game implementation or deployment has been performed. The original client bundle and English localization were retrieved and inspected as text; the original game was not run. A later installation's stage data was inspected separately. The proposed recreation has not been benchmarked.

The intended starting direction is a faithful revival with a documented AI-assisted build. This is a recommendation pending the user's product preferences, not a settled implementation contract.
